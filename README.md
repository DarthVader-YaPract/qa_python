# qa_python

Учебный проект с тестами для класса `BooksCollector`. Тесты написаны на `pytest`
и проверяют работу с книгами, жанрами и списком избранного.

## Реализованные тесты

- добавление двух книг;
- запрет повторного добавления одной и той же книги;
- проверка недопустимой длины названия книги с помощью параметризации;
- установка и получение жанра книги;
- получение книг определённого жанра;
- исключение книг с возрастным рейтингом из списка книг для детей;
- добавление книги в избранное без повторов;
- удаление книги из избранного;
- получение списка избранных книг.

## Запуск тестов

```bash
pytest -v tests.py
```
